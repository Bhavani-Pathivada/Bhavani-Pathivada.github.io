# 💫 Vibin & Bhavani — Wedding Invitation Website

A beautiful space & stars themed wedding invitation website.

---

## 🚀 How to Deploy on GitHub Pages

1. **Create a new GitHub repository** (e.g. `vibin-bhavani-wedding`)
2. **Upload these files** into the repository root:
   - `index.html`
   - `bgm.mp3` ← your chosen song (see below)
3. Go to **Settings → Pages**
4. Under **Source**, select `Deploy from a branch` → `main` branch → `/ (root)`
5. Click **Save**
6. Your site will be live at: `https://yourusername.github.io/vibin-bhavani-wedding/`

---

## 🎵 Adding Your BGM

The website is set up to play a file called `bgm.mp3` from the same folder.

1. Download your chosen Malayalam song (e.g. *Kalyaana Maalai* from *Thirumanam Enum Nikkah*, or any romantic Malayalam song you love)
2. Convert/rename it to **`bgm.mp3`**
3. Place it in the same folder as `index.html`
4. Push to GitHub — done!

> 💡 The music player has a play/pause button at the bottom-right corner.
> Autoplay is disabled by design (browsers block it); guests click ▶ to start.
